This file contains a report of a project in which a publication figure from a research article was reproduced. The figure chosen was a  UMAP plot showing 16 color-coded cell clusters of 80,919 raw single-cell transcriptomes from CSF cells from N-COVID taken from the paper *Neurological Manifestations of COVID-19 Feature T Cell Exhaustion and Dedifferentiated Monocytes in Cerebrospinal Fluid* published in the journal Immunity.
